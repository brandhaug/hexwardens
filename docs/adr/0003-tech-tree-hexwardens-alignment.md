# Align the Tech Tree to Hexwardens' Six-Path Structure

The tech tree adopts Hexwardens' canonical shape: six Paths — five elemental Paths (Water, Plants, Earth, Fire, Mineral) shaped as `basic + econ-secondary + mil-secondary + Mastery`, plus a linear utility Mobility Path (Climbing → Road & Seaports → Market → Mobility Mastery). Per-village research cost scaling is retained (`+1g per Village beyond the first`). Spiritualism, Medicine, and Siegecraft are dropped, along with the units they gated (Healer, Shaman, Giant); Healer's role is replaced by the Recover self-heal action. Internal Tech names are renamed to match Hexwardens (Roads → Road & Seaports, Watercraft → Water & Bomber, Engineering → Cannon, Smithing → Swordsman, Chivalry → Knight, etc.), and each Mastery unlocks a "Large" upgrade for its Path's economic-tier-2 building.

Considered: keeping our 6-path tree as-is with the support Techs as deliberate divergence, or going further and collapsing to 5 elemental Paths plus standalone Climbing/Roads/Market utility Techs. The first kept divergence we couldn't justify against the project's stated "make it as Hexwardens" bar; the second was ruled out once the wiki confirmed Mobility _is_ a sixth Path with the same Mastery-tip structure (`Mobility Mastery: +1 movement to all units`). The remaining gap with Hexwardens is internal naming and unlock placement, not shape.

Twelve visual terrain types are retained but mapped onto five functional Path families (Plants: Grass/Tundra/Snow; Earth: Forest/Jungle/Swamp; Fire: Desert/Barren; Mineral: Mountain/Terraced/Ice; Water: Water+Coral Reef sub-feature) so the building set remains aligned 1:1 with Path Masteries while preserving sprite work and Tribe-terrain identity.
